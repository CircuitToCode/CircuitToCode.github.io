NITYANAND SWAMI — ENGINEERING PORTFOLIO
======================================

WEBSITE STRUCTURE
- index.html: Main professional profile homepage.
- projects.html: Separate projects landing page, opened by the "My Projects" link.
- projects/: Individual project detail pages.
- assets/style.css: Website styling.
- assets/script.js: Mobile navigation and footer year.

HOW TO PREVIEW
1. Extract this ZIP file.
2. Open the folder.
3. Double-click index.html to open the homepage in Chrome or Edge.
4. Click "My Projects" to open the separate project portfolio.

HOW TO EDIT
- Open HTML/CSS files in Visual Studio Code.
- Replace draft project text with verified details.
- Add approved project images in assets/ or each project's folder.
- Add your resume PDF as assets/Nityanand_Swami_Resume.pdf and link it from index.html.
- Update email, LinkedIn, education and experience if anything changes.

PUBLISHING
You can host this static website using GitHub Pages or another static website host.
The homepage and projects page are separate URLs within the same website.

IMPORTANT
Project descriptions are starter drafts based on information discussed. Review them before publishing.
Do not upload confidential employer/customer drawings, process parameters, production data,
source files or reports unless you have permission. Clearly mark concepts and work-in-progress items.
